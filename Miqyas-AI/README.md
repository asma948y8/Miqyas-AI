# Miqyas AI | مِقياس

**من عروض متعددة إلى قرار أوضح | From Multiple Offers to Clearer Decisions**

## 📌 نبذة عن المشروع | About the Project

**مِقياس (Miqyas AI)** هو تطبيق ويب يهدف إلى أتمتة عملية مقارنة عروض الموردين وفق معايير محددة، مما يساعد على تقليل الوقت والجهد المبذول في المقارنة اليدوية، وتنظيم البيانات، وتوضيح الفروقات بين العروض لدعم اتخاذ القرار.

يتيح التطبيق رفع ملفات عروض الموردين وتحليل بياناتها ومقارنة الأسعار ومدد التسليم والضمانات، مع عرض النتائج والملاحظات بصورة منظمة. كما يمكن الاستفادة من الذكاء الاصطناعي باستخدام Google Gemini لتلخيص المعلومات عند تفعيل التكامل.

Miqyas AI is a web application designed to automate supplier offer comparison based on defined criteria. It helps reduce manual effort, organize data, identify differences between offers, and support informed decision-making.

## 🎯 أهداف المشروع | Project Objectives

- أتمتة المهام المتكررة المرتبطة بمقارنة عروض الموردين.
- تقليل الوقت المستغرق في مراجعة العروض يدويًا.
- توحيد معايير المقارنة وتحسين تنظيم البيانات.
- توضيح الفروقات بين الأسعار ومدد التسليم والضمانات.
- الاستفادة من الذكاء الاصطناعي في تلخيص بيانات العروض عند تفعيل Google Gemini.
- دعم اتخاذ القرار مع إبقاء المراجعة النهائية بيد المستخدم.

## 🔄 مسار الأتمتة | Automation Workflow

1. **إدخال البيانات:** رفع ملف CSV أو Excel يحتوي على عروض الموردين.
2. **استخراج البيانات:** قراءة معلومات الموردين وتنظيمها لتسهيل المقارنة.
3. **مقارنة العروض:** تقييم الأسعار ومدد التسليم والضمانات وفق المعايير المحددة.
4. **تحليل النتائج:** تحديد الفروقات بين العروض وإظهار المعلومات الناقصة أو الملاحظات.
5. **تلخيص النتائج:** عرض ملخص واضح للمقارنة، مع إمكانية استخدام Google Gemini لتلخيص المعلومات عند تفعيل التكامل.
6. **المراجعة البشرية:** مراجعة النتائج والتحقق منها قبل اتخاذ قرار الشراء.

## ✨ المميزات | Features

- مقارنة عروض الموردين وفق معايير محددة.
- دعم رفع ملفات CSV وExcel.
- تنظيم بيانات العروض وعرض نتائج المقارنة.
- توضيح الفروقات في الأسعار ومدد التسليم والضمانات.
- واجهة تدعم اللغتين العربية والإنجليزية.
- إمكانية التكامل مع Google Gemini لتلخيص المعلومات.
- استخدام SQLite لتخزين البيانات.
- تشغيل التطبيق محليًا.
